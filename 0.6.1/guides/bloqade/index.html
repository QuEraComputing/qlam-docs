    Bloqade SDK

    Bloqade is QuEra's open-source Python SDK for building and simulating neutral-atom quantum programs as well as submitting them to hardware.

    Documentation

    For comprehensive documentation, tutorials, and API reference, visit:

    bloqade.quera.com

    The Bloqade documentation includes:

    • Installation and setup guides
    • Programming tutorials
    • Simulation options
    • Hardware submission workflows
    • API reference
