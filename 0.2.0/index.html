    QLAM Platform Documentation

    Welcome to the Quantum Layer Access Management (QLAM) platform documentation.

    What is QLAM?

    QLAM is a REST API platform that provides access to QuEra's neutral-atom quantum computers. There are optional "qlam packages" to install, but you may interact with QLAM through HTTP requests using your preferred client:

    • Bloqade SDK - Python SDK for building and running quantum programs
    • QLAM Shell - Command-line interface for task management
    • Third-Party SDKs - Integrate other Python SDKs using the QLAM Core library
    • Direct API access - Use any HTTP client (curl, Python requests, etc.)
